# ADR-0001: Deployment Approach

## Status
Accepted

## Context
We deploy the OpenTelemetry Demo to a GKE Standard regional cluster. Helm deployments are decoupled from Terraform to maintain clear responsibility boundaries. Kubeconfig is stored in Google Secret Manager so both local and CI workflows can retrieve it on demand.

## Decision
- Use a GKE Standard regional cluster across three zones.
- Provision infrastructure with Terraform only.
- Store kubeconfig in GSM after cluster creation.
- Deploy applications with Helm using the stored kubeconfig.

## Consequences
- Workflows require access to GSM to fetch kubeconfig.
- Terraform and Helm can evolve independently.
